## v0.2.5

### 고친 것 — 「의견 보내기」
- **키보드로도 누를 수 있습니다.** Tab 으로 「새 버전 확인」 다음에 「의견 보내기」로 가고(Shift+Tab 은 거꾸로), Enter·Space 로 엽니다. 초점이 오면 테두리가 파란색으로 바뀌어 보이고, 버튼 크기는 그대로입니다.
- **마우스를 올리면 짧은 설명이 뜹니다.** 0.45초쯤 올려 두면 「안 되는 것·불편한 것·바라는 기능을 알려 주세요(브라우저가 열립니다)」가 버튼 아래에 나오고, 벗어나거나 누르면 사라집니다. 창이 화면 가장자리에 있어도 창·화면 밖으로 잘리지 않고, 언어를 바꾸면 설명도 바로 바뀝니다.
- **어느 페이지를 여는지 한 규칙으로 맞췄습니다.** 화면 언어가 한국어면 한국어 툴 페이지, 그 밖의 언어는 모두 영어 판 툴 페이지를 엽니다. 「의견 보내기」와 새 버전 알림의 「업데이트」가 같은 규칙을 씁니다.
- README 일본어·중국어 판의 툴 페이지 링크를 영어 판 페이지로 바꿨습니다.

프로그램은 여전히 아무것도 보내지 않고, 페이지를 브라우저로 열기만 합니다. 의견은 [툴 페이지의 의견 칸](https://chaekgalpi.co.kr/tools/ebookrenamer#feedback)에서 로그인 없이 보낼 수 있습니다(영어: [Send feedback](https://chaekgalpi.co.kr/en/tools/ebookrenamer#feedback)).

### 확인
- 자동 시험: 키보드(Tab 순서·Enter·Space·다른 키 무반응·초점 표시와 크기), 툴팁(지연·사라짐·클릭·4개 언어 문구·떠 있는 동안 언어 바꾸기·가장 작은 창을 화면 왼쪽·오른쪽 끝과 화면 밖에 걸쳐 둔 경우), 페이지 언어 규칙(ko·ko-KR·ko_KR 은 한국어, en·ja·zh·zh-TW·fr·de·목록에 없는 코드는 영어, 값이 없으면 기본 화면 언어), README 4개 언어의 의견 링크. 실제 네트워크·실제 브라우저는 쓰지 않습니다.
